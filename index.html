Work

Six projects

All open source, all with a README that explains the decisions rather than listing features. Two are live and being used by people who aren't me.

wayfare

TypeScript · Next.js

A travel planner that looks up real prices before writing anything, then tells you honestly whether your budget works. Accounts, saved trips, and a map colour-coded by day, so you can see whether the plan has you crossing the city three times before lunch.

Runs on three AI providers in sequence, because the first two kept running out.

silbe

Python · MLX

A German language model trained from scratch on a MacBook Air. No pretrained weights - random numbers, 531 MB of Wikipedia, and a laptop with no fan. It writes grammatical German and confidently invents every fact in it.

Reproduced the shape of the scaling law on a laptop, which I did not expect to work.

transformertokenizersNumPy Code →

matchbox

Kotlin · Spring Boot

A limit order book - the part of a stock exchange that decides who trades with whom and at what price. Best price first, and among equal prices whoever arrived first. Postgres, GraphQL, Docker, 39 tests.

My first JVM project, written after reading a job ad that asked for Kotlin.

JVMTestcontainersCI Code →

job-pulse-de

Python · NLP

A dashboard of the German Werkstudent and junior job market - which skills come up, how many postings actually state pay, how realistic they are for a student. Three sources, including an undocumented Bundesagentur endpoint.

Publishes its own error rates, because a dashboard that hides them is a confident guess.

pandasGerman NLPStreamlit Live → Code →

rag-research-agent

Python · LangGraph

An agent that researches a topic by choosing its own next move - search the web, check what it already knows, or answer. With a step limit, so it stops instead of searching forever.

Built twice, by hand and with LangGraph. Both versions are in the repo.

agentsChromaDBRAG Code →

rag-bench

Python · evaluation

Most RAG demos show you that an answer came out. This one scores whether the answer was any good - four metrics, judged by a second model, with the working shown.

The results table says which model did the judging. Surprisingly rare.
